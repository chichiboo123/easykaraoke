# V2 리모델링 계획 — 블록 에디터

목표: **초등학생도 음원과 가사만 있으면 만들 수 있는 노래방 반주 에디터.**
모델: VREW의 자막 클립처럼 **가사 한 줄 = 블록 하나**를 다루는 편집.

---

## 1. 무엇을 바꾸는가

### 1.1 가장 큰 전환 — 음절 스탬핑에서 블록 스탬핑으로

| | V1 | V2 |
|---|---|---|
| 타이밍 입력 단위 | **음절** | **줄(블록)** |
| 4분 곡 기준 Space 횟수 | 300~500회 | **20~40회** |
| 한 번 실수했을 때 | 그 뒤가 전부 밀림 | 그 블록 하나만 다시 |
| 음절 타이밍 | 사람이 직접 | **줄 길이 안에서 자동 분배** |

음절 타이밍은 블록의 `start`–`end` 구간을 **글자 수와 받침 유무로 가중 분배**해 자동 계산합니다. 노래방 하이라이트는 음절이 "차오르기만" 하면 되므로, 줄 단위 정확도만 있으면 충분히 자연스럽습니다. 세밀하게 다듬고 싶으면 블록을 펼쳐 음절을 개별 조정할 수 있습니다.

### 1.2 5단계 → 3단계

```
V1  ① 반주 → ② 가사 → ③ 타이밍 → ④ 디자인 → ⑤ 내보내기
V2  ① 준비(음원+가사) → ② 만들기(블록 에디터) → ③ 꾸미기·저장
```

②에 **미리보기·트랜스포트·파형·블록 트랙·블록 카드**가 전부 모입니다. 화면을 오갈 필요가 없습니다.

### 1.3 렌더링 모델

`#app.innerHTML` 전면 교체를 버리고 **마운트 1회 + 부분 갱신**으로 바꿉니다. 스탬프는 DOM write 몇 개로 끝나고, 파형·블록·재생헤드는 **Canvas 하나**가 rAF로 그립니다. 그 결과 A–B 구간·확대·스크롤·포커스가 살아남습니다.

## 2. V1 결함 대응표

| V1 문제 | V2 해결 |
|---|---|
| 음절 길이 0.35초 고정 (보정문 미실행) | 블록 `end`가 음절 끝을 확정. 자동 분배로 항상 연속 |
| 하이라이트가 공백만큼 왼쪽으로 밀림 | `Segment`에 원문 오프셋 `charStart`/`charEnd` 보존, 원문 부분문자열로 x 계산 |
| 내보내기 1회 후 오디오 영구 무음 | `MediaElementAudioSourceNode`를 모듈 수준 1회 생성·재사용, `close()` 안 함, `finally` 정리 |
| 입력 지연 보정 없음 | `e.timeStamp` 보정 + **전역 오프셋 슬라이더(±1s)** + 0.5×/0.75× 재생 |
| Space마다 A–B·확대·스크롤 리셋 | 부분 갱신 + 상태를 프로젝트에 저장 |
| 타임라인 클릭해도 시크 안 됨 | Canvas 타임라인 클릭 = 시크, 드래그 = 블록 경계 조절 |
| 파형·볼륨이 1단계에만 | 트랜스포트와 파형을 ②로 통합, 파형 디코드 결과 캐시 |
| 가사 재적용이 타이밍을 말없이 파괴 | 텍스트 diff 병합 — 같은 줄은 타이밍 유지, 손실 시 확인 |
| Ctrl+Z가 UI에 없음 | 트랜스포트에 `↶ ↷` 버튼 상시 노출 |
| 드래그&드롭 문구만 있고 미동작 | 실제 구현 + `window` 레벨 이탈 차단 |
| 글꼴 6종이 전부 같아 보임 | 로드 실패 카드 비활성 + 배지, 기본값을 실재 글꼴로 |
| 프리셋 썸네일 색 ≠ 결과 색 | 썸네일을 `renderFrame()`으로 직접 그림 |
| 카운트다운이 죽은 코드 | 마커 UI 없이 **인트로 카운트다운을 기본 제공** |
| 부분 타이밍이면 내보내기 불가 | 부분 내보내기 허용 + **구간 시험 렌더** |
| 긴 가사가 화면 밖으로 넘침 | 2줄 자동 줄바꿈, 다음 가사에도 `fit()` |
| 배경 이미지 찌그러짐 | cover 계산 + blur 오프스크린 1회 전처리 |
| 색 26종·간격 23종, 토큰 0 | CSS 변수 토큰 + **다크 우선 편집 UI** |
| 위치 의존 선택자 | 의미 기반 클래스로 전면 교체 |
| 키보드로 파일 선택 불가 | 포커스 가능한 파일 버튼 |
| iOS 미지원을 5단계에서야 안내 | 시작 화면에서 미리 안내 |

## 3. 구조

```
src/
  types.ts            V2 스키마 + V1 마이그레이션
  app.ts              진입점 · 스토어 · 라우팅 · 단축키
  lib/
    lyrics.ts         음절 분리(원문 오프셋 보존) · diff 병합 · 자동 분배
    frame.ts          시간 → 블록/진행률 (순수 함수)
    renderer.ts       1920×1080 Canvas 출력
    audio.ts          오디오 그래프 1회 생성 · 속도 · 볼륨 · 파형 캐시
    timeline.ts       파형+블록+재생헤드 Canvas · 시크 · 드래그
    fonts.ts          글꼴 로드 + 실패 상태
    storage.ts        IndexedDB (Blob은 변경 시에만 기록)
    exporter.ts       내보내기 (부분·구간·WebM 허용)
    ui/
      shell.ts        껍데기 · 토스트 · 파일 버튼
      prepare.ts      ① 준비
      studio.ts       ② 만들기 (핵심)
      finish.ts       ③ 꾸미기 · 저장
```

빌드 파이프라인(`tsc` → `dist` → 루트 동기화)은 그대로 유지합니다.

## 4. ② 만들기 화면

```
┌────────────────────────────────────────────────┐
│                미리보기 16:9                     │
├────────────────────────────────────────────────┤
│ ▶  00:42.3 / 03:20   0.5× 0.75× 1×  🔊  ↶ ↷    │
├────────────────────────────────────────────────┤
│ 파형 · 블록 · 재생헤드  (Canvas 하나)            │
├────────────────────────────────────────────────┤
│ ▸ 지금 찍을 줄:  우리 함께 문을 열어             │
│   [Space 눌러서 찍기]                            │
├────────────────────────────────────────────────┤
│ 1  00:12.4 → 00:15.1  우리 함께 문을 열어   ↻ ✎ │
│ 2  00:15.1 → 00:18.0  세상 밖으로           ↻ ✎ │
│ 3  아직 안 찍음        노래해요 다같이       ↻ ✎ │
└────────────────────────────────────────────────┘
```

- 재생 중 줄이 시작될 때 <kbd>Space</kbd> 한 번. 다음 Space가 이전 줄의 끝을 확정합니다.
- 블록 카드를 클릭하면 그 시각으로 이동, `↻`는 그 줄만 다시 찍기, `✎`는 텍스트 수정(타이밍 유지).
- 타임라인에서 블록 양 끝을 드래그해 길이 조절.
